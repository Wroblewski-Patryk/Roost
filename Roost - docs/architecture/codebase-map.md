## Purpose

Map the current repository structure to product, architecture, and module
ownership.

This file is a human-readable companion to the architecture registry. It helps
agents orient before they edit code.

## Repository Areas

| Path | Owner / module | Role | Notes |
| --- | --- | --- | --- |
| `src/` | application | Source code placeholder. | Replace with real paths. |
| `tests/` | testing | Test roots. | Replace with real commands. |
| `docs/` | documentation | Current source-of-truth docs. | Keep history elsewhere. |
| `history/` | documentation/history | Old tasks, audits, evidence, releases, artifacts. | Not current truth. |

## Maintenance Rule

When a new runtime root, package, app, worker, integration, or major module is
added, update this map plus the architecture registry.
