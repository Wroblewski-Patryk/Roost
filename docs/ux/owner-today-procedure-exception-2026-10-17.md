## Implementation and local evidence

A manual or human-review step enters Current if it has no outcome and its Task is `done`, or if its latest outcome is `exception` regardless of Task status. The exception row uses the outcome timestamp, high severity, its complete recorded reason and exact pinned run/step target; workspace and owner restrictions remain. An associated blocked Task is suppressed only while that latest exception is current. A later accepted assessment removes the exception card while the run retains both assessments. The existing outcome command and its audit/idempotency contract are unchanged. No migration was introduced.
