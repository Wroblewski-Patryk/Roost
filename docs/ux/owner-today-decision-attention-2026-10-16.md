## Local implementation

Today projects the responsible Decision principal from current mandate and impact state inside a serializable read-only transaction. It compares the current impact and authority with the latest recorded preview before naming a delegate. A stale preview, blocked authority or missing exact active agent grants names the owner as the next coordinator and explains the blocker in PL/EN. The exact `decisionId` link opens the existing governance detail. If the record becomes historical before navigation, the History redirect retains the Today return origin; invalid or unavailable exact IDs also offer that return. Accepting a Decision removes it from the pending Today query but does not reclassify the accepted Decision as History.

The disposable API test covers owner attribution, exact target and context, foreign and invalid ID refusal, impact drift, stale acceptance refusal, refreshed review and acceptance, Today removal, and retained Current governance audit. The browser fixtures exercise the PL/EN reason states, narrow/wide layout, keyboard exact link, actual routed Today → governance modal → acceptance → Today refresh → Current audit, and stale-link return. No company data, model or Worker is needed for these local fixtures.
