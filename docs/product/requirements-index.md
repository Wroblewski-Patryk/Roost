# Requirements navigation

The complete [requirements registry](requirements.md) is the sole authority for
accepted clauses, decision state and supersession. This file only directs an
agent to the relevant section. It is not a summary of the requirements and
does not claim implementation. For one gate, read the exact IDs it names plus
applicable cross-cutting security, authority, data and review clauses. For a
whole-product coverage audit, read the complete registry and the
[traceability matrix](../architecture/traceability-matrix.md).

Read the registry's [maintenance](requirements.md#maintenance-and-provenance)
and [precedence](requirements.md#product-direction-and-precedence) rules before
changing accepted intent. Current work and authorization live in
[`implementation.md`](../implementation.md), not in requirement rows.
