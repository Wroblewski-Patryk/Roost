# Product Overview

## Plain-Language Summary

Roost is the operational core for a small company that wants one workspace,
one API/MCP boundary, and one human-and-agent-ready source of truth for work,
knowledge, integrations, and governance. It is for an owner or operator who
needs to set up company context, inspect real operating state, import
knowledge, hand out scoped agent access, and keep the system auditable. The
current shipped direction matters because Roost already has a zero-gap
user-facing completion index, but it still needs a bounded and honest
commercial/readiness contract. The first shipped version must do workspace
scoping, owner console control, API/MCP safety, imported knowledge access,
and manual operations reliability well.

## Current Phase

- Phase: `v1.0 guided pilot / guided sale readiness`
- Primary outcome for this phase: sell or grant access to Roost as a guided,
  owner-operated operational core with supervised/read-only agent boundaries.
- What is intentionally out of scope: self-serve SaaS onboarding, hosted
  Paperclip V1 as a default path, broad autonomous provider writes, advanced
  RBAC, billing, and native mobile.
