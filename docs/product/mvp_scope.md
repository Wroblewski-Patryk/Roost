# MVP Scope

## In Scope

- Owner-operated web console for workspace-scoped operational visibility and
  safe setup flows.
- Workspace-scoped HTTP API and MCP bridge with scoped service keys and
  supervised command boundaries.
- Read-oriented knowledge-plane foundation through imported Google Drive
  context, notes, decisions, and company operating readback.

## Out Of Scope

- Self-serve commercialization flows such as billing, invitations, and
  advanced RBAC.
- Broad autonomous provider writes, hosted Paperclip V1 as a default
  production path, and unsupervised destructive MCP execution.

## MVP Quality Bar

- Minimum usable flows: owner login and workspace context, protected API/MCP
  handshake, imported knowledge readback, scoped API-key visibility, and
  documented manual deploy/smoke.
- Required validation: zero-gap app-completion index, current architecture
  contract alignment, security baseline adherence, and dated ops evidence for
  the approved rollout path.
- Required deployment readiness: manual VPS/Coolify rollout, health/smoke
  documentation, rollback notes, and no overclaim beyond the guided v1.0
  boundary.
