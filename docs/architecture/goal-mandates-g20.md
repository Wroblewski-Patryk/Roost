# G20 goal mandates and observed economics

## Commissioned boundary

The owner authorized one Goals and economics gate. Its production proof is read-only; no numeric company target or real measurement was supplied for creation. The positive journey uses fictional records in an isolated database. G20 does not qualify a model, set a cost budget, or start G21.

## Records and authority

`Goal` remains the stable workspace record. A draft `goal_mandate_versions` row declares the measurable result, metric, unit, target, evidence source, accountable member, provenance, and separately typed binding deadline, uncertain forecast and execution schedule. The owner previews affected tasks, Targets, existing measurements and Ready tasks. A 15-minute, one-use preview receipt binds owner, goal, draft, previous version and an impact digest. A fresh owner action proof and a serializable recheck are required to adopt. The head points to one adopted version; prior versions remain historical. Adoption invalidates linked Ready pins. Existing Goal, Target and Metric fields are legacy and do not establish accepted progress. Their ordinary editing path is closed when linked to an adopted mandate, with database guards for races.

`goal_measurements` stores observed value, date, evidence identity/revision/digest, version, proposer and decision. The evidence must be verified and attached to the same goal or to the exact linked task. An assigned agent with a live task-bound credential can only read the current mandate and propose a task-evidence measurement through API/MCP. The write holds a task-row lock while it rechecks assignment. Owner review rechecks source and version before acceptance. The owner can record a goal-evidence measurement directly. Mutated, unverified, moved or missing evidence makes an accepted observation stale in the projection; the older row remains auditable. A proposal never changes accepted progress. Earlier Target `currentValue` and Metric `currentValue` are explicitly labeled unverified legacy data.

Queue-time execution columns retain goal, mandate version and parent goal attribution, so a later task relink cannot rewrite recorded execution history. Historical executions without this snapshot remain unattributed rather than being assigned from today's task link. The owner view exposes linked tasks, observed execution elapsed time, attempts, independent review outcomes and returns. List rows are bounded; totals count all attributed executions and the view marks omitted rows. The latest accepted measurement is fetched independently of the bounded history page. Hermes provider token and cost receipts are absent; even a Worker-reported zero remains `unknown` without a server-verified no-model witness. Human effort is unknown unless a future trustworthy observation is added. These are descriptive economics, not a cost or productivity judgment.

## Isolation and limits

The owner route requires a workspace owner session; adoption also requires a recent proof for the exact request. The accountable membership participates in the impact digest and is rechecked at adoption. If it later disappears, the owner sees an explicit warning, while agent context and measurement writes no longer receive a current mandate; the existing membership source watch invalidates Ready when that context changes. The agent route rechecks the active credential, workforce identity, exact assigned task and current mandate. Drafts, superseded versions, owner economics and other tasks are not exposed there. Composite foreign keys bind mandates and measurements to the same workspace and goal. Verified evidence is rechecked at write and read time. The database administrator remains a trusted boundary.

The accepted goal does not make a claim about the company's actual baseline or economic value. A binding deadline is not a forecast, and an execution schedule is not an observed cost. These distinctions remain visible in PL/EN owner UI. Current priority policy is not replaced by a numeric-target shortcut; unresolved trade-offs still require the authorized human decision.
