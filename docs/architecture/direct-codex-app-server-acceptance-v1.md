# Direct App Server adapter v1 acceptance matrix

RF-HERMES-005, 2026-09-13. Matrix version: **1**.
Normative owner: [contract v1](direct-codex-app-server-contract-v1.md).
Exactly 30 requirements CAS-R01..CAS-R30 map one-to-one to CAS-T01..CAS-T30.
Each row's positive and negative families are both mandatory; repeated parameter
variants count as cases within the row, not exceptions or untracked requirements.

Evidence levels: **D** static documentation/schema/decision review; **S** hermetic
synthetic transport/process tests; **C** exact pinned real App Server compatibility;
**O** native supported-OS enforcement/crash/escape proof; **A** independent authority
and admission review. C/O with a model or external effects require separate task
authority. Test receipts bind artifact/profile/schema hashes, OS, scenario,
expected/observed result, counters, redacted evidence and reviewer identity through
opaque references. No sensitive raw traces enter this repository.

**Current status for every row: SPECIFIED, NOT QUALIFIED.** RF002's 29 fake cases
are research evidence only and are not marked as passing this new matrix.
Static completeness/link validation establishes D structure only, not resolved
decisions, implemented enforcement or any S/C/O/A outcome.
